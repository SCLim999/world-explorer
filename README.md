# 🌍 环游世界小课堂 · World Explorer for Kids

给小学一年级小朋友的世界地理网页，中英文双语，可离线使用。
A bilingual (Chinese + English) world geography web page for Grade 1 kids. Works fully offline.

## 打开方式 · How to open

双击 `index.html`，用任意浏览器打开即可。不需要安装、不需要联网。
Just double-click `index.html` in any browser. No install, no internet needed.

## 功能 · Features

**📚 学习 Learn**
- **40 个国家**，按洲分类（亚洲 / 欧洲 / 非洲 / 北美洲 / 南美洲 / 大洋洲）
- **国家卡片** — 国旗、中英文国名、首都、3 条一年级能懂的小知识、当地「你好」怎么说
- **国家三宝** — 每个国家的 🏛️ 地标建筑、🐾 代表动物、🌸 国花
- **🔍 特写小知识** — 点三宝任一张图，弹出大图特写，配 1–2 条小知识（长城有多长、袋鼠一跳多远、金字塔用了多少块石头…），并自动朗读中英文
- **🧊 12 座建筑是真 3D** — 长城、双子塔、婆罗浮屠、哈利法塔、比萨斜塔、帕特农神庙、金字塔、奇琴伊察，以及四座已经消失的古代奇迹（阿尔忒弥斯神庙、摩索拉斯陵墓、亚历山大灯塔、空中花园）。会自己慢慢转，也可以用手指拖着转、上下翻。卡片上标了 🧊 的地标，点开就是 3D
- **🌏 3D 地球** — 会自转，可拖动；点国家后地球自动飞过去并插上小旗
- **🔍 放大 · ⛶ 全屏** — 地球可以放大到 4 倍看清一小块地方（滚轮 / 两指捏合 / 按钮都行），也可以整个铺满屏幕
- **🚄🚢✈️ 旅行动画** — 换国家时，交通工具会沿着航线在地球上走过去；工具按路线自动选：陆路坐火车、近海坐轮船、远洋坐飞机
- **🌊 海洋名称** — 地球上标注 15 片海洋与海域（太平洋、大西洋、印度洋、北冰洋、南冰洋、地中海、南海、东海、爪哇海、孟加拉湾、加勒比海、墨西哥湾、塔斯曼海、英吉利海峡、北海），旅行时会告诉小朋友这趟要跨过哪一片海和大约多少公里
- **🌗 昼夜地球** — 地球上画出真实的晨昏线，夜半球会暗下来，☀️ 标出此刻太阳正照在哪里；卡片上还会写出当地现在几点、那边的小朋友在做什么（起床 / 上学 / 吃晚饭 / 睡觉），可一键关闭
- **✈️ 飞机在飞** — 地球上随时有七架小飞机在真实的国家之间飞，身后拖着长长的白色航迹；飞到夜半球时机身会暗下来，只剩一盏一闪一闪的小灯。点一点小飞机，会告诉你「这架飞机从日本飞去墨西哥，大约 11,305 公里」，可一键关闭
- **🏠 我的家** — 第一次打开时选一个自己住的国家，之后每张卡片都会算出「离你家多少公里、坐什么、大约要多久」
- **⚖️ 比一比** — 把面积和人口换算成「几个你家」：「巴西有 26 个马来西亚那么大」「中国的人有 41 个马来西亚那么多」
- **📋 小档案** — 当地时间、离家距离、面积比、人口比排成整齐的四张小卡，每张都是「图标 + 大数字 + 一句说明」，一眼扫完
- **📮 每日一国** — 每天推荐一个国家，全世界同一天看到的是同一个，去过就打勾

**📜 世界历史 World history**（把所有历史课串起来的那条主线）
- **一条从山洞画画到今天的时间线**，分成 8 个时代：🦣 很久很久以前 · 🏺 最早的文明 · 🏛️ 古代大帝国 · 🏰 中世纪 ·
  ⛵ 大航海时代 · 🚂 机器的时代 · ✈️ 一百年前 · 🚀 我们的时代；一共 **37 站**，每一站都是真实的年份和地点
- **▶️ 播放：历史在地球上走一遍** — 年份和时代跟着跳，地球飞到那个地方，走过的站会用时代的颜色连成一条线，
  一眼看出人类怎么从两河流域走到希腊、走到长安、走到大海上、再走到月亮
- **📏 按真实比例看看** — 时间线默认每个时代一样宽（不然石器时代会把最近五百年挤成一根头发）；
  按一下，所有的点会滑到**真实的线性比例**上 —— 你听说过的事情，几乎全挤在最右边那一点点里。这一下比讲十遍都管用
- **和别的模式连起来** — 苏美尔文字、金字塔、兵马俑、两次大战…… 这些站上有「去看这一段 ➜」，一按就跳进 🏺 古文明 / 🏛️ 八大奇迹 / 🕊️ 两次大战 的完整故事
- **最后一站是「你」** — 今天，位置就在你设的「我的家」上：**你现在做的事，也会变成以后的历史**
- 地球上的每个小圆点都可以点，下面还有一份按时代分组的目录，想跳哪站跳哪站

**🏺 四大文明 Ancient civilisations**
- **古巴比伦 / 古埃及 / 古印度 / 古中国** 四张卡片，各有发源的大河、距今多少年、3 条小知识、以及「现在这块地方是哪个国家」（可一键跳过去看那个国家）
- **大河画在地球上** — 尼罗河、幼发拉底河和底格里斯河、印度河、黄河都按真实走向画出来，选中哪个文明，哪条河就亮起来；4 个发源地在地球上闪着，可以直接点
- **⏳ 时间轴** — 四个文明按「距今多少年」排在一条轴上，一眼看出谁最老（巴比伦 5500 → 埃及 5100 → 印度 4600 → 中国 4000）
- 核心那句话写在最上面：**四大文明都是在大河边上长大的**

**🏛️ 世界八大奇迹 The eight wonders**
- **古代七大奇迹 + 兵马俑** — 金字塔、巴比伦空中花园、阿尔忒弥斯神庙、宙斯神像、摩索拉斯陵墓、罗得岛太阳神巨像、亚历山大灯塔，再加上被称为「第八大奇迹」的秦始皇兵马俑，按建成年代从早到晚排
- **还在 / 消失了** — 每一个都标清楚现在还能不能看到；地球上 <b>实心</b> 的圆点是还站着的，<b>虚线空心</b> 的是已经消失的 —— 一眼就看出七个古代奇迹里只剩金字塔
- **后来呢？** — 每个奇迹都写了它是怎么没的：被地震震塌、被人放火烧掉、掉进海里，或者根本没人找到过
- 每个奇迹有专属插画和 3 条小知识，还能一键跳到它今天所在的国家

**🧭 特别的地方 Special places**
- 地球上有些地方**不是国家**，所以不放在 40 个国家里，另开一类：**香港、台湾、百慕大三角、撒哈拉沙漠、亚马逊雨林、南极洲、北极、马里亚纳海沟、大堡礁、死海**
- 每个都标明它到底是什么（一座城市 / 一座岛 / 一片海 / 一片沙漠 / 浮在海上的冰…），配 3 条小知识
- **10 个地方都是 3D 小景**，会自己转、也能用手指拖着转：香港的摩天大楼群、台湾的中央山脉、百慕大三角真的是三根柱子拉出一个三角形、撒哈拉的沙丘、亚马逊的树冠、南极的冰山和企鹅、北极的浮冰和北极熊、马里亚纳海沟一层层往下沉的方井、大堡礁的珊瑚、死海上浮着的人
- **是「一片」的会在地球上画出范围** — 百慕大三角真的画成一个虚线三角形（佛罗里达—百慕大—波多黎各），撒哈拉、亚马逊、大堡礁也有轮廓
- 旁边有国家的（香港→中国、撒哈拉→摩洛哥、亚马逊→巴西、大堡礁→澳大利亚）可以一键跳过去看

**🕊️ 两次大战 The two world wars**（会动的历史课，最后落在「和平」上）
- **一战 1914–1918 · 二战 1937–1945** 两张时间轴，都是真实的日期和地点，用一年级小朋友听得懂的话讲
- **▶️ 播放：看着战争在地球上蔓延** —— 年份一年一年往上跳，每个国家在**它真正被卷进去的那一年**在地球上亮起来，
  蓝色是协约国 / 同盟国，橙色是同盟国 / 轴心国，灰白的是一直中立的国家；亮起来的那一下会有一圈涟漪扩出去。
  点地球上任何一个圆点，它会告诉你「英国，1914 年加入协约国」
- **🁢 多米诺骨牌** — 一战为什么会从一次刺杀变成全欧洲开打？六张牌（奥匈—塞尔维亚—俄—德—法—英）一张碰倒一张，一看就懂
- **数字会自己跑** — 「失去生命的人数」从 0 一直数上去（一战 1500 万 / 二战 7000 万），
  再换算成小朋友能想象的大小：**「差不多是 2 个马来西亚的人，全都没能回家」**（会用你设定的「我的家」来比）
- **每场战争都以和平收尾** — 一战的最后一格是**国际联盟**，二战的最后一格是**联合国**：40 面国旗从地球中间飞出来围成一圈
- **纪念** — 一战配一片会一朵朵开出来的**虞美人花**（11 月 11 日戴的那种），二战配一排**会跳动的烛火**
- **🕊️ 放飞和平鸽** — 一按，几十只鸽子拍着翅膀从屏幕下面飞上去；播放到最后一格也会自动放飞
- 最后是**小朋友能做的四件事**：有话好好说、看到有人被欺负去帮他、和不一样的人做朋友、记住那些没能回家的人

**🧱 搭建工坊 Build workshop**（类似 Minecraft Education 的搭建课）
- 给一张图纸，**一层一层用方块把真实建筑搭出来**，**12 个国家 12 座建筑**（按钮上就是那个国家的国旗）：
  🇪🇬 金字塔 · 🇨🇳 长城 · 🇬🇷 帕特农神庙 · 🇲🇽 奇琴伊察 · 🇮🇩 婆罗浮屠 · 🇮🇳 泰姬陵（古代）
  🇲🇾 双子塔 · 🇦🇪 哈利法塔 · 🇫🇷 埃菲尔铁塔 · 🇬🇧 大本钟 · 🇩🇪 新天鹅堡 · 🇸🇬 滨海湾金沙（现代）

- 搭完会撒花，并可以一键 **「看看真的」** 跳到那个国家，对比刚才亲手搭的和真实的 3D 模型
- 还有 **✨ 自由搭建**，想搭什么搭什么；每张图纸和自由搭建各自存进浏览器，关掉再打开还在

## 技术说明 · Notes

- 单文件，零依赖：HTML + CSS + 原生 JavaScript
- 界面分组：11 个模式按 **认识世界 / 动手玩 / 游戏** 三组排列（每个模式仍然一键直达，只是不再是一整排按钮）；
  🔊 朗读是设置不是模式，所以挪到语言切换旁边，并用绿色和语言按钮区分开
- 手机上的处理：地球下面那排按钮只留图标、洲名标签变成可横向滑动的一行、国旗格子从 2 列变 3–4 列 —— 首页比原来短了约四分之一
- 宽屏时地球面板 `position:sticky`，跟着卡片一起往下走，不再在左边留一大块空白
- 40 面国旗 + 40 个地标建筑全部为内嵌手绘 SVG（Windows 不支持 emoji 国旗，故未使用 emoji）
- 40 种国花由参数化 SVG 生成（花瓣数 / 花瓣形状 / 颜色）
- 地球为 canvas 正射投影（orthographic projection）实时绘制，海陆轮廓为简化坐标数据
- 昼夜由太阳赤纬和时角算出真实的太阳直射点，夜半球用一张 100×100 的软遮罩贴在球面上，所以晨昏线像真的一样带一圈渐变
- 当地时间用浏览器自带的 `Intl.DateTimeFormat` + IANA 时区（`FACTS` 表里的 `tz`），夏令时自动正确
- 奖状用 `@media print` 打印，不依赖任何外部服务
- 飞机沿大圆航线飞，航迹按段画、越靠近机头越亮；它们画在夜幕之前，所以飞进夜里会自动变暗，闪灯再补画在夜幕之上
- 3D 建筑是真的 CSS 3D，不是贴图：每个立方体 / 金字塔 / 圆柱 / 屋顶都由若干块平面 `<i>` 用 `translate3d` 摆在空间里，父层 `transform-style:preserve-3d` 交给浏览器做透视和前后遮挡；每个面按朝向调明暗，所以看得出体积。模型定义在 `MODELS`，尺寸表 `M3SIZE` 用来自动缩放居中 —— 扁平的风景（沙漠、浮冰、百慕大三角）会自动改成俯视角度，高的塔楼保持平视。自转交给 CSS 动画（合成器线程），手指拖动时才切到 JS，松手后从当前角度接着转。
  注意：3D 里画横杠的函数叫 `bar3` 而不是 `edge` —— `edge()` 已经被国花花瓣描边占用了
- 漫游世界不用 CSS 3D，而是自己在 canvas 上写的软件渲染器：顶点变换到相机空间 → 近平面裁剪 → 背面剔除 → 按距离从远到近排序填充。
  为什么不用 CSS 3D：CSS 只能按元素排序，人一旦站进场景内部就会出现「透过墙看到墙」的错乱
- 漫游世界的场景本身是一张**体素表** `W3.vox`（`"gx,gy,gz" -> 方块名`）：画什么、能踩在哪、准星指到哪，全都是从它推出来的，
  所以创意模式的增删不需要任何特例。走路的碰撞就是「这一格上面最高的方块」（`groundG`）加「头顶两格空不空」（`fitsAt`），
  差一格以内自动抬高，所以金字塔的台阶不用特别处理就能爬。准星是把视线方向按 1/3 格步进往前走，
  记住最后一个空格子（放方块的位置）和第一个实心格子（挖掉的位置）
- 世界历史那条线有**两套坐标**：`eqPos()` 让每个时代占一样宽，`realPos()` 是真正的线性年份，
  画的时候在两者之间插值（`histPos`），按钮只是把插值系数从 0 动画到 1 —— 所以「按真实比例」是同一批点滑过去，不是换一张图
- 两次大战的时间轴按「事件」走，不按年份走：每个事件在屏幕上停一样久（2.4 秒），中间的年份数字在两个真实日期之间插值，
  所以 1914 年挤在一起的三件事不会一闪而过，而 1916 到 1917 的空档也不会干等。参战国的 `y` 是**参战年份的小数**
  （比如美国 1917.29 = 1917 年 4 月），地球上的圆点就按这个一个一个亮起来 —— 「战火蔓延」是数据自己走出来的，不是画的动画
- 这一课有意不用夜幕：在 `war` 模式下昼夜遮罩和飞机都关掉，否则一半的国家亮在黑夜里就看不出蔓延的顺序了
- 搭建工坊的图纸不是手写的方块表，而是用 `bpRing` / `bpFill` 这类小函数**程序生成**的（见 `BP` 数组），
  所以一座金字塔只要 4 行；搭建进度存在 `localStorage` 的 `we_build_v1`，每张图纸一个槽位
- 放大和全屏：地球的放大改的是投影半径 `RR`（所以放大后是真的看得更清楚，不是把画面拉伸）；漫游的放大改的是视野角 `fov`，
  相当于换长焦镜头。全屏用标准 Fullscreen API，通过 body 上的 `fs-globe` / `fs-roam` 类来切换样式，避开 `:fullscreen` 的浏览器前缀问题
- 浏览器里保存的东西（`localStorage`）：护照 `we_passport_v1`、我的家 `we_home_v1`、名字 `we_name_v1`、每日一国 `we_daily_v1`、昼夜开关 `we_daynight_v1`、飞机开关 `we_planes_v1`、搭建工坊 `we_build_v1`、漫游世界的创意改动 `we_roam_v1`（每个场景一个槽位）

## 添加国家 · Adding a country

1. 在 `index.html` 的 `COUNTRIES` 数组中照格式加一条（含 `lat` / `lon` 经纬度）
2. 在 `FLAGS` 对象中加上对应的国旗绘制函数
3. 在 `FACTS` 中加上时区 `tz`（IANA 名字）、面积 `area`（平方公里）、人口 `pop`
   （另外三套数据是独立的：`CIVS` + `RIVERS` + `CIVART` 是四大文明，`WONDERS` + `WONART` 是八大奇迹，
   `PLACES` + `PLACEART` 是不属于任何国家的特别地方 —— 那里的条目**不进** `COUNTRIES`，也不参与国旗、护照和游戏）
4. 在 `EXTRA` 中加上该国的地标 / 动物 / 国花，地标图形加在 `LM` 对象里
5. 在 `DETAIL` 中加上三宝的特写小知识（地标 / 动物各 1–2 条，国花 1 条）
6. 想让它出现在「动物找家」游戏里，再往 `ANIMALS` 数组加一条
