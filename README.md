# 🌍 环游世界小课堂 · World Explorer for Kids

给小学一年级小朋友的世界地理网页，中英文双语，可离线使用。
A bilingual (Chinese + English) world geography web page for Grade 1 kids. Works fully offline.

## 打开方式 · How to open

双击 `index.html`，用任意浏览器打开即可。不需要安装、不需要联网。
Just double-click `index.html` in any browser. No install, no internet needed.

## 功能 · Features

**📚 学习 Learn**
- **40 个国家**，按洲分类（亚洲 / 欧洲 / 非洲 / 北美洲 / 南美洲 / 大洋洲）
- **国家卡片** — 国旗、中英文国名、首都、3 条一年级能懂的小知识、当地「你好」怎么说
- **国家三宝** — 每个国家的 🏛️ 地标建筑、🐾 代表动物、🌸 国花
- **🔍 特写小知识** — 点三宝任一张图，弹出大图特写，配 1–2 条小知识（长城有多长、袋鼠一跳多远、金字塔用了多少块石头…），并自动朗读中英文
- **🌏 3D 地球** — 会自转，可拖动；点国家后地球自动飞过去并插上小旗
- **🚄🚢✈️ 旅行动画** — 换国家时，交通工具会沿着航线在地球上走过去；工具按路线自动选：陆路坐火车、近海坐轮船、远洋坐飞机
- **🌊 海洋名称** — 地球上标注 15 片海洋与海域（太平洋、大西洋、印度洋、北冰洋、南冰洋、地中海、南海、东海、爪哇海、孟加拉湾、加勒比海、墨西哥湾、塔斯曼海、英吉利海峡、北海），旅行时会告诉小朋友这趟要跨过哪一片海和大约多少公里
- **🌗 昼夜地球** — 地球上画出真实的晨昏线，夜半球会暗下来，☀️ 标出此刻太阳正照在哪里；卡片上还会写出当地现在几点、那边的小朋友在做什么（起床 / 上学 / 吃晚饭 / 睡觉），可一键关闭
- **✈️ 飞机在飞** — 地球上随时有七架小飞机在真实的国家之间飞，身后拖着长长的白色航迹；飞到夜半球时机身会暗下来，只剩一盏一闪一闪的小灯。点一点小飞机，会告诉你「这架飞机从日本飞去墨西哥，大约 11,305 公里」，可一键关闭
- **🏠 我的家** — 第一次打开时选一个自己住的国家，之后每张卡片都会算出「离你家多少公里、坐什么、大约要多久」
- **⚖️ 比一比** — 把面积和人口换算成「几个你家」：「巴西有 26 个马来西亚那么大」「中国的人有 41 个马来西亚那么多」
- **📮 每日一国** — 每天推荐一个国家，全世界同一天看到的是同一个，去过就打勾

**🏺 四大文明 Ancient civilisations**
- **古巴比伦 / 古埃及 / 古印度 / 古中国** 四张卡片，各有发源的大河、距今多少年、3 条小知识、以及「现在这块地方是哪个国家」（可一键跳过去看那个国家）
- **大河画在地球上** — 尼罗河、幼发拉底河和底格里斯河、印度河、黄河都按真实走向画出来，选中哪个文明，哪条河就亮起来；4 个发源地在地球上闪着，可以直接点
- **⏳ 时间轴** — 四个文明按「距今多少年」排在一条轴上，一眼看出谁最老（巴比伦 5500 → 埃及 5100 → 印度 4600 → 中国 4000）
- 核心那句话写在最上面：**四大文明都是在大河边上长大的**

**🎮 四个游戏 Games**
- **🎯 地球寻宝** — 「在地球上找到日本！」转动地球找出目标国家，答错会提示所在大洲和方向
- **🐾 动物找家** — 把小动物配对回它的国家，配对成功会说出「袋鼠住在澳大利亚」
- **🚩 国旗配对** — 8 道选国旗的题，答错会显示正确答案
- **🛂 环游世界护照** — 每认识一个新国家就盖一个章，40 个集满有奖状；进度自动保存在浏览器里
- **🖨️ 可打印奖状** — 在护照里填上名字就能打印一张奖状，上面有去过的所有国旗和日期

**🔊 语音 · 🈳 双语**
- 所有游戏全程中英文朗读（浏览器语音合成），可一键关闭
- 三档语言切换：中英对照 / 纯中文 / 纯英文

## 技术说明 · Notes

- 单文件，零依赖：HTML + CSS + 原生 JavaScript
- 40 面国旗 + 40 个地标建筑全部为内嵌手绘 SVG（Windows 不支持 emoji 国旗，故未使用 emoji）
- 40 种国花由参数化 SVG 生成（花瓣数 / 花瓣形状 / 颜色）
- 地球为 canvas 正射投影（orthographic projection）实时绘制，海陆轮廓为简化坐标数据
- 昼夜由太阳赤纬和时角算出真实的太阳直射点，夜半球用一张 100×100 的软遮罩贴在球面上，所以晨昏线像真的一样带一圈渐变
- 当地时间用浏览器自带的 `Intl.DateTimeFormat` + IANA 时区（`FACTS` 表里的 `tz`），夏令时自动正确
- 奖状用 `@media print` 打印，不依赖任何外部服务
- 飞机沿大圆航线飞，航迹按段画、越靠近机头越亮；它们画在夜幕之前，所以飞进夜里会自动变暗，闪灯再补画在夜幕之上
- 浏览器里保存的东西（`localStorage`）：护照 `we_passport_v1`、我的家 `we_home_v1`、名字 `we_name_v1`、每日一国 `we_daily_v1`、昼夜开关 `we_daynight_v1`、飞机开关 `we_planes_v1`

## 添加国家 · Adding a country

1. 在 `index.html` 的 `COUNTRIES` 数组中照格式加一条（含 `lat` / `lon` 经纬度）
2. 在 `FLAGS` 对象中加上对应的国旗绘制函数
3. 在 `FACTS` 中加上时区 `tz`（IANA 名字）、面积 `area`（平方公里）、人口 `pop`
   （古文明是另一套数据：`CIVS` 存四大文明，`RIVERS` 存大河的经纬度路径，`CIVART` 存插画）
4. 在 `EXTRA` 中加上该国的地标 / 动物 / 国花，地标图形加在 `LM` 对象里
5. 在 `DETAIL` 中加上三宝的特写小知识（地标 / 动物各 1–2 条，国花 1 条）
6. 想让它出现在「动物找家」游戏里，再往 `ANIMALS` 数组加一条
